## When dealing with memory there is two question to think about:
    - What is the type of the memory
    - When to update the memory.

there is a 3 types of memories for a human:
    - Semantic (Facts -> (`bike model I have`))
    - Episodic (Memories -> (`Bike rides I took`))
    - Procedural (Instructions -> (`Motor Skills`))

there is a 3 types of memories for an agent:
    - Semantic (Facts -> (`Facts about a user`))
    - Episodic (Memories -> (`Past Agent actions`))
    - Procedural (Instructions -> (`Agent's system prompt`))
